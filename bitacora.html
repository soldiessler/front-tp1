Cómo llegamos
hasta acá.

Registro de decisiones del desarrollo del TP1.

01

INICIO

Organización

Definimos la estructura del repositorio, las páginas necesarias y una identidad visual común.

02

DISEÑO

Identidad visual

Tomamos como referencia una estética editorial, cálida y experimental: fondo crema, terracota como acento, tipografía grande, tarjetas y espacios amplios.

03

DESARROLLO

HTML + CSS + JS

Construimos primero la estructura semántica y luego aplicamos Grid, Flexbox, media queries y animaciones.

04

PRUEBAS

Responsive

Revisamos el comportamiento en 400 px, 900 px y 1200 px. También comprobamos navegación, formularios, estados de foco y funcionamiento de las interacciones.

05

PUBLICACIÓN

GitHub + Vercel

El repositorio se mantiene público y la versión final se publica mediante Vercel.
